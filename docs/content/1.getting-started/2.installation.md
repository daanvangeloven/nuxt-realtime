## Install the package

::code-group
```bash [pnpm]
pnpm add nuxt-realtime
```

```bash [npm]
npm install nuxt-realtime
```

```bash [yarn]
yarn add nuxt-realtime
```
::

## Add to your config

Add `nuxt-realtime` to your modules and enable WebSocket support in Nitro:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-realtime'],

  nitro: {
    experimental: {
      websocket: true,
    },
  },
})
```

That's it. You can now use the realtime composables in your components.

::callout{to="/getting-started/configuration" icon="i-lucide-settings"}
See the **Configuration** page to set up storage, Redis, Socket.IO options, and key cleanup.
::

## Requirements

- Nuxt 3.x or Nuxt 4.x
- Node.js 18+
- WebSocket support enabled in Nitro
